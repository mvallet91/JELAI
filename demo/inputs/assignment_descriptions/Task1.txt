Task 1: Shark Inventory. The student is a new analyst at the Oceanic Research Institute (ORI). The goal is to load the shark tracking dataset sharks.csv, do a basic inspection, and find the number of unique sharks recorded for each species. The dataset has one row for each location report of a tagged shark, with the columns: active, datetime, id, latitude, longitude, name, gender, species, weight, length, tagDate, dist_total. One shark has many rows. The steps are: (1) load the CSV file into a DataFrame named sharks_df with pandas, (2) find the number of rows and columns, (3) show the column names and data types, (4) identify the columns that the question needs (species, and name or id), (5) check for missing values in these columns, (6) count the unique sharks for each species (group by species and count unique names or ids; value_counts on species counts observations, not sharks), (7) interpret which species have the most and the fewest individuals, (8) summarize the finding and reflect on the learning process, (9) ask for the report with /report and select a next step.
